# Ghostleaf v0.1.0

The first release. A private, offline reader for Windows and Linux with a
physical-feeling page curl and a stealth mode.

## What's in it

- **Formats:** PDF (rendered with its own embedded fonts), TXT (encoding detection, including Thai TIS-620), CSV / TSV (paginated tables).
- **Page turning:** 3D page curl from any corner or edge, slide, or none. Drag, click the page edges, mouse wheel or keyboard.
- **Paper sounds** with a one-key mute (`M`) and a volume setting.
- **Stealth reading:** the page hides when the mouse leaves the window (adjustable delay), with Veil or Minimize styles and a global boss key (`Ctrl+Alt+H`).
- **Display:** single page, two-page spread or automatic; left-to-right or right-to-left; first blank page toggle.
- **Themes:** Light, Paper, Sepia, Tan, Dusk, Dark, Black, and a custom tint. The title bar can match the theme, use the system style, or be hidden.
- **Library:** covers and progress, bookmarks, resume where you left off, drag and drop to add.
- **Languages:** English and Thai.

## Private by design

- No network code at all: no accounts, telemetry, ads or update checks. CI fails the build if a networking library enters the dependency tree.
- Books stay where they are; Ghostleaf stores only the path, your position, bookmarks and settings, as plain JSON.
- The Privacy screen lists every stored file and can forget one book or wipe everything.
- Portable mode: put a file named `portable.flag` next to the app and all data stays in that folder.

## Install

Unzip and run; nothing to install.

- **Windows x64:** `Ghostleaf-0.1.0-windows-x64.zip`
- **Linux x64:** `Ghostleaf-0.1.0-linux-x64.tar.gz`

Check downloads against `SHA256SUMS.txt`.

## Known limits

- Password-protected PDFs aren't supported yet.
- No EPUB, CBZ, MOBI or Markdown yet (see the roadmap in `docs/PLAN.md`).
- Android builds exist in CI but aren't part of this release.
- On Linux under Wayland, the global boss key and always-on-top depend on the compositor.
